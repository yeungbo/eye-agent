# 眼科针灸与外治

> 提炼自《针灸学》(`通用中医/38`~`通用中医/41`)并据眼科特点重组。本文件放眼科穴位(定位主治+危险区)、**非药物手段安全分级(A/A⁻/B)**、眼病病证配穴、眼保健操、灸法按摩与外治要领、眼区按压红线。取穴定位法见 `通用中医/38`(骨度分寸/同身寸,已内置本技能 `references/通用中医/`)。**针刺、穴位注射、头针、耳针、瘢痕灸、发泡疗法等有创外治绝对禁自行——只解释原理与风险、指路专业机构**。

## 一、非药物手段安全分级(眼科适用,继承 `通用中医/40` 灸法按摩与外治法)

| 级别 | 手段 | 眼科适用说明 |
|---|---|---|
| **A(可直接执行)** | 眼局部热敷/熏洗(外用,非点眼)、远眺运目、眼保健操、轻按安全穴(攒竹/四白/太阳/风池/光明等)、清洁睑缘 | 必须连同要领禁忌一起给;眼区危险穴(睛明/承泣/球后)家庭不按压不灸 |
| **A⁻(须教全要领禁忌)** | 艾条悬灸(远端穴如足三里/肝俞/肾俞保健灸)、耳穴压豆(耳穴"眼""肝""肾") | 实热证不灸、孕妇腹腰骶不灸;防烫伤;不做"裸建议" |
| **B(禁自行,只指路)** | 针刺、拔罐、穴位注射、头针、耳针、瘢痕灸、发泡、一切点眼药/眼用制剂 | 只解释原理与风险,指路执业针灸师/中医眼科医师;点眼药一律就医开具 |

## 三、眼病病证配穴(主穴+加减;家庭只做安全穴轻按或A级,针刺只指路)

| 病证 | 配穴(主+加减) | 级别与说明 |
|---|---|---|
| 目赤肿痛(外障风热) | 攒竹、太阳、风池、合谷、太冲;热甚加曲池 | 家庭轻按安全穴(A);刺络放血/毫针=B 指路 |
| 目涩昏花(内障虚) | 睛明(不按)、攒竹、四白、风池、光明、肝俞、肾俞、太溪;保健灸肝俞肾俞足三里(A⁻) | 虚证调补,远端配穴+A⁻灸 |
| 近视(能近怯远) | 攒竹、四白、太阳、风池、光明、承泣(不按);耳穴眼肝肾压豆(A⁻) | 配镜+行为干预为主;穴按辅助 |
| 迎风流泪(冷泪) | 攒竹、四白、风池、肝俞、肾俞 | 温补肝肾,灸法(A⁻)辅助 |
| 眼睑下垂(上胞下垂) | 攒竹、阳白、丝竹空、足三里、脾俞(灸) | 虚证重灸(A⁻),神经科排查 |
| 麦粒肿(针眼未溃) | 太阳(放血=B)、攒竹、合谷、曲池;局部热敷(A) | 热敷+清洁(A),放血/针=B指路 |
| 视疲劳 | 攒竹、四白、太阳、风池、光明 | 远眺运目+轻按(A) |
| 绿风内障(急性) | — | **红线急症,立即就医,不取穴**;平证期保健从肝(太冲/肝俞灸)辅助 |

## 四、眼保健操与运目(纯 A 级,可自行)
1. **按揉攒竹/四白/太阳/风池**:每穴轻按揉 1~2 分钟,力度以酸胀不痛为度,不深压眼球。
2. **运目法(远眺运目)**:闭目养神 1 分钟→睁眼远眺(6米以上)3~5 分钟,或眼球缓慢上下左右转动各数次——**缓解久视伤血**。
3. **熨目**:搓热双手敷眼(闭目),温通气血。
4. **禁忌**:眼区危险穴(睛明/承泣/球后)不按压;眼部有红肿热痛、视力异常时先就医,不自行按摩;高血压/青光眼患者运目幅度宜缓,绿风发作时禁。

## 五、灸法、按摩与外治要领
- **保健灸**(A⁻):足三里、肝俞、肾俞、关元,悬灸每穴 10~15 分钟,**实热证(目赤肿痛实火、绿风发作)不灸、孕妇腹腰骶不灸、禁灸穴不灸**;防烫伤。
- **热敷/熏洗**(A):麦粒肿未溃、针眼、轻症红眼、眼疲劳——温热毛巾敷或菊花/桑叶/蒲公英煎汤**温热熏洗眼部(闭眼,药液不入口不点眼)**;温度试腕内侧不烫方可。
- **按摩十法**(A):眼周轻摩、远端穴按揉,同 `通用中医/40` 按摩十法;不追求重力。
- **点眼药/眼用散剂**(B):炉甘石/硼砂/冰片类只可建议就医开具,**严禁指导自制点眼**(见 `安全` 与安全表)。
- **耳穴压豆**(A⁻):耳穴"眼""肝""肾""神门"贴压,辅助近视/视疲/内障调护,须清洁防感染。

## 六、古籍增补:审视瑶函针灸要穴与外治要义(v1.2,已通读落盘)

> 原文见 `sources/审视瑶函.txt`;条文整理见 `08-眼科经典条文` 第四节之 5。以下内容**只作知识讲解与理解医师治疗的参考:歌括中的毫针取穴属 B 级、钩割/针拨属 C 级禁区,家庭绝对禁自行**。

### 1. 眼科针灸要穴歌括(通治与分症)

- **通治**:"睛明治眼若未效,合谷光明不可缺"(目疾久治不效,合谷、光明为要)。
- **迎风冷泪/目中出泪**:头临泣兼头维。
- **视物昏蒙(目漠漠)**:攒竹兼三间。
- **雀目(夜盲)**:睛明兼行间。
- **头晕目眩**:风池。

| 歌括取穴 | 家庭可做(仅安全穴轻按,A 级) | 不可做 |
|---|---|---|
| 睛明、合谷、光明 | 合谷、光明轻按 | **睛明为眼区危险穴,不按压不灸**;毫针属 B 级指路 |
| 头临泣、头维 | 二穴轻按 | 头维禁灸 |
| 攒竹、三间 | 攒竹轻按;三间(手食指本节后桡侧凹陷)轻按 | |
| 睛明、行间 | 行间(足背第1、2趾缝端)轻按 | 睛明毫针属 B 级指路 |
| 风池 | 朝鼻尖方向轻按 | 不向咽喉深压 |

### 2. 钩割针烙宜戒慎(仅知识层面,操作一律 B 级指路)

- 古法:气血肉三轮疾患(胬肉攀睛、鸡冠蚬肉、赤脉虬筋、胞肉粘轮等)**可**钩割;**大眦红肉为"心之英"决不可割**;风轮浅薄者误割则破珠(眼球穿孔)。
- 现代立场:上述割烙一律由眼科医师评估手术,家庭/非医疗场所绝对不做。
- **点药总则**:"内疾已成、外症若无,不必点;外有红丝赤脉初发,点可消;外障既成,不点不去"——点眼药须就医开具,严禁自制(见安全表)。

### 3. 金针拨内障十六般(只解释,绝不指导)

- 古法金针拨治内障(圆翳、滑翳、涩翳、浮翳、横翳、冰翳、偃月、枣花、散翳、黑水凝翳、惊振、白翳黄心及五风变内障等,详见 `08`),已由现代白内障手术取代;"金针一拨日当空"仅作史识与医患沟通话题——**针刺入眼属 C 级禁区,任何情况下不得自行或指导他人操作**。

## 七、红线提醒(外治不替代急救)
凡视力骤降、眼痛剧伴头痛呕吐虹视、眼球穿通伤、化学伤、异物嵌顿、小儿瞳神发白夜盲——**一律先指眼科急诊,任何穴位/外治不替代**。
