# 眼科病因病机与诊断

> 提炼自《中医眼科学》总论。本文件放眼科病因、内障外障分野、气血津液在目,以及眼科四诊(望目、问诊十问、脉诊)与内障外障鉴别。五轮定位见 `01`,辨证套路见 `03`,病种见 `04`。

## 一、眼科病因

### 1. 外感六淫(外障主因)
- **风**:风为阳邪、善行数变、上先受之——目痒、碜涩、流泪、胞睑肿胀、黑睛生翳(聚星障),多夹寒夹热夹湿。**风轮、气轮外障之首因**。
- **火(热)**:火性炎上、伤津生风动血——目赤肿痛、眵多、碜痛、黑睛溃烂、迫血妄行(目衄/眼底出血)。**实火多从心(血轮)、肝(风轮)、肺(气轮)**。
- **湿**:重浊黏腻、缠绵——睑缘湿烂、眵泪胶黏、白睛黄浊、黑睛晦暗翳障难消(湿翳)。多夹热(湿热)或夹风(风湿)。
- **燥**:干涩——白睛干涩、目珠干燥(白涩症/神水将枯)、秋燥多发。
- **寒**:少见,寒凝可致头目痛、脉络瘀滞。
- **暑**:夏月发热目赤,多从风热/湿热论治。

### 2. 内伤(内障与慢病主因)
- **脏腑虚损**:**肝肾不足**(老花、圆翳内障、青盲、高风内障、视瞻昏渺)、**脾胃虚弱/气陷**(上胞下垂、视物易疲劳、能近怯远少年发)、**心脾两虚**(视疲、血虚目暗)、**脾肾阳虚**(夜盲、疳积上目后期)。
- **气血失和**:**气虚**→目失所养(视物易疲、上胞下垂);**血虚**→目涩夜盲(肝血不足);**血瘀**→目暗、眼底出血、外伤瘀滞(撞击伤目、络阻/络损暴盲);**气滞**→胀痛、绿风诱发。
- **津液失常**:燥伤津液(干涩)、痰湿(胞生痰核、视瞻有色渗出)。

### 3. 七情(内障诱发与加重)
- 郁怒伤肝→肝阳/肝火/肝风,**是绿风内障(急性青光眼)发作的重要诱因**;思虑伤心脾→血虚目暗;惊恐伤肾→神光不得发越。

### 4. 饮食劳逸
- 过食肥甘厚味、辛辣→脾胃湿热(睑弦赤烂、针眼、胞生痰核);饮酒助火;**久视伤血**(久读久屏)→肝血耗、目涩昏花;劳倦、房劳→肾精亏(内障早发)。

### 5. 外伤(眼外伤专类,见 `04`)
- 撞击、异物、酸碱热烫、真睛破损——直接伤目,多夹血瘀、外邪,重者失明。

### 6. 先天与全身病
- 胎禀不足(高风内障、先天性内障);**消渴(糖尿病)→消渴目病(视网膜病变)**、**眩晕(高血压)→高血压眼底**为现代多发,内障辨证须结合全身(见 `04` 末)。

## 二、内障与外障(眼科最基本的病位分野)

| | **外障** | **内障** |
|---|---|---|
| 病位 | 胞睑、两眦、白睛、黑睛(五轮之前四轮,肉眼可见) | 瞳神及瞳神以内(晶状体、玻璃体、眼底、视神经) |
| 主症 | 红、肿、痛、痒、眵、泪、翳(黑睛生翳)、睑肿核 | 视力下降、视物昏花/变形、眼前黑影、瞳神变色变形、眼内自觉症少而外症不显 |
| 病因 | 六淫外邪为主,经络受邪 | 脏腑内伤(肝肾气血)为主,或外邪内传 |
| 虚实 | 多实(风火湿热) | 多虚(肝肾不足、气血亏)或虚实夹杂 |
| 辨证 | 五轮 + 六淫经络 | 五轮(水轮)+ 脏腑气血津液 |
| 致盲性 | 一般较低(愈后多不留障,但凝脂翳可留癜) | **高**(瞳神疾患直接损目,多不可逆) |
| 红线意识 | 红痛剧伴视力降/绿风征象即升级 | **凡视力骤降/瞳神异常即红线**,立即就医 |

**鉴别眼目**:外障"外症显而视力多不影响或轻影响";内障"外症不显而视力神光先伤"。临床最易误判——**患者主诉'眼睛红'却视力骤降,可能是绿风内障而非普通红眼,必须查瞳神与眼压**(红线)。

## 三、气血津液在目的失常

- **气**:气帅血行、目赖气养。气虚→目失养(易疲、下垂);气滞→胀痛、神光被遏(绿风前期)。
- **血**:目得血而能视。血虚→目涩、夜盲、视物模糊;血瘀→目暗、眼底出血、外伤瘀肿、暴盲(络阻/络损);血热→目赤、迫血妄行(目衄、玻璃体出血)。
- **津液**:上濡目珠。津伤→干涩(白涩症);痰湿→痰核、渗出(视瞻有色)。

## 四、眼科诊法

### 1. 望目(眼科第一诊,细化 `通用中医/09` 望诊闻诊的目部内容)
- **望眼神(目之有神无神)**:目光灵活、精彩内含=有神(精气未伤);**目暗睛迷、目无精彩=失神/精气衰(重症、疳积上目后期)**;**瞳仁散大固定=危重(绿风、脱证、脑病)**。
- **望目色**:①**目眦赤=心火**;②**白睛赤=肺火/肺经风热**;③**胞睑红肿=脾火/脾胃湿热**;④**全目赤肿=肝经风热/肝火上炎**;⑤**白睛黄染=黄疸**(全身病);⑥**目窠微肿如卧蚕=水肿初起**。
- **望目态**:**睑废(上胞下垂)=脾肾亏/脾气虚**;**横目斜视/戴眼反折(目睛上视)=肝风/惊风痉厥**;**目窝凹陷=阴液耗损**;**流泪不止=泪窍不束(迎风流泪/泪道病)**。
- **望五轮局部**(结合 `01` 五轮):黑睛有无翳障(聚星/凝脂/花翳)、白睛有无红赤结节(火疳)、瞳神是否清莹/散大/变色(绿风/青风/圆翳)、晶状体是否混浊(圆翳内障)。**注:细部须裂隙灯/眼底检查,文字描述仅作初步筛查**。
- **望眵泪**:眵多黄稠=实热;眵稀白=虚寒/风湿;泪热=风热;冷泪=肝肾虚寒(迎风流泪)。

### 2. 眼科问诊十问(主诉采集专用,优于通用十问歌)
1. **视力**:单/双眼?骤降/渐降?视物模糊/变形/变色/黑影?
2. **目痛**:部位(眼眶/眼球/眉棱)、性质(刺痛/胀痛/灼痛/隐痛)、持续/阵发、拒按/喜按?
3. **红赤**:何部红?伴肿?眵多否?
4. **痒**:风盛之征,时复目痒(春季结膜炎)有季节性。
5. **干涩**:津伤/血虚/久视。
6. **畏光(羞明)**:黑睛病(凝脂翳)、瞳神紧小多剧。
7. **流泪**:热泪(外障风热)/冷泪(迎风流泪,肝肾虚寒)。
8. **目胀/头眼胀痛**:**绿风内障(急性青光眼)关键症,伴头痛恶心呕吐虹视**。
9. **全身兼症**:口苦(肝)、口干(燥/阴虚)、神疲(虚)、消渴(血糖)、眩晕(血压)、便溏/便秘(脾胃)、月经(血虚)。
10. **诱因与病史**:外感/劳倦/情志(郁怒诱发绿风)/外伤/全身病(糖网、高眼底)/用药(激素、散瞳、降眼压药)/屈光(近视)。

### 3. 眼科脉诊(28 脉通用,见 `通用中医/10` 问诊切诊脉诊部分;此处点眼科相关)
- **弦脉**:肝、痛、绿风内障/肝阳上亢常见。
- **数脉**:热(外障实火、内障虚火)。
- **细/弱脉**:虚(血虚、气虚、肝肾不足)。
- **涩脉**:血瘀(眼底出血、外伤、络阻暴盲)。
- **脉只测率与律**(静坐数 30 秒×2 得率、感节律齐否),脉形脉势不自测,如实说明只能靠医师面诊。

### 4. 切诊与他查
- 按诊:眶痛拒按(实)、喜按(虚);颈前动脉区(人迎)禁按(`07`)。
- **科技/专科数据主动询问**:验光、眼压、眼底照相、OCT、血糖血压——有则采信作红线分流与辨证佐证,不伪对应。

## 五、红线条目速查(见 `04` 各病种"红线指征",此处总览)
- 视力骤降/丧失、眼痛剧伴头痛呕吐虹视、眼球穿通伤、化学伤、异物嵌顿、小儿瞳神发白夜盲/畏光揉眼——**一律先指眼科急诊,不进辨证**。
