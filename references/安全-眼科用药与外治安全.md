# 安全-眼科用药与外治安全

> **⚠ 硬约束文件**:凡涉及具体药物、成方、点眼药、外治,必先过本表。本表聚焦**眼科特有红线**;通用十八反十九畏、妊娠分级、毒性药剂量总表见本技能内置 `通用中医/安全-配伍妊娠禁忌与毒性药.md`(本库眼科分支在其基础上提炼,凡本表未列者一律回查该总表,不凭记忆判定"安全")。古方剂量为教材参考值,**未经《中华人民共和国药典》校准**——涉毒性药剂量须加此声明。

## 一、眼科红色禁令(最高优先级)

1. **青光眼(绿风内障/青风内障)患者——绝对禁用一切扩瞳倾向药**
   - **青葙子**:有扩瞳作用,青光眼患者禁用(`05` 已注)。含青葙子的成方(**石决明散、石斛夜光丸、磁朱丸意**等)青光眼患者一律回避。
   - **洋金花(曼陀罗、风茄子)**:莨菪烷类,强扩瞳、升高眼压,**青光眼禁用**;且中毒可致瞳孔散大、视物模糊、谵妄(详见下方毒性表)。
   - 机理:扩瞳可诱发或加剧房角关闭、眼压骤升,致不可逆视神经损伤。**凡处方/食疗中出现上述药,青光眼患者须特别提示"与开方医师确认"。**

2. **点眼药、眼用散剂——严禁指导自制,只建议就医开具**
   - 炉甘石、硼砂、冰片、珍珠等眼用制剂,只可建议"由眼科医师开具正规制剂";**自制点眼(含张锡纯磨翳水/磨翳散、护眉神应散等外用眼药)一律存目禁自制**——眼部给药剂量与无菌要求极高,误用致角膜损伤/感染。
   - 即便外用熏洗(菊花/桑叶/蒲公英煎汤熏眼)也须明确"闭眼、药液不入口不点眼、温度试腕不烫",与"点眼药"严格区分。

3. **眼区危险穴——家庭不按压不灸**
   - 睛明、承泣、球后(**见 `07`**):眼区危险穴,家庭不按压、禁灸;仅医师针刺/眼科操作。
   - 颈前动脉区(人迎等):禁按揉(颈动脉窦受压可心率骤降晕厥)。

4. **有创外治——绝对禁自行**
   - 针刺、穴位注射、头针、耳针、瘢痕灸、发泡、针拨内障术——只解释原理与风险,指路执业中医眼科医师/针灸师。**针拨内障(金针拨内障)为专业手术,家庭绝不可为**。

## 二、通用配伍与妊娠(眼科相关摘录;全表见 `通用中医/安全-配伍妊娠禁忌与毒性药.md`)

- **十八反十九畏**:眼科常用反药——**藜芦反诸参辛芍**(玄参、丹参、白芍、人参等反藜芦,`05` 各药已注);**甘草反甘遂大戟芫花海藻**、**乌头反半蒌贝蔹及**、**水银/砒霜类**——处方内逐对排查,一律按禁忌处理。
- **妊娠分级**:孕妇禁用/慎用群体——活血破瘀药(桃仁、红花、牛膝、三棱莪术、水蛭)、降下引血下行(牛膝)、辛温走窜(细辛)、重镇(代赭石、磁石慎用)、**合谷穴孕妇不宜按压**。处方/配穴须过 `通用中医/安全-配伍妊娠禁忌与毒性药.md` 妊娠节。
- **毒性药眼科相关剂量**(教材上限,须医师定夺;未经药典校准):
  | 药 | 毒性 | 眼科相关要点 |
  |---|---|---|
  | 洋金花(曼陀罗) | 有毒 | 入丸散 **0.2~0.6g**;含东莨菪碱,中毒:口干瞳孔散大视物模糊、皮肤潮红心率快、谵妄抽搐,重者呼吸麻痹死亡;**青光眼、高血压、心动过速禁用**;孕妇体弱慎;救治:毛果芸香碱/毒扁豆碱 |
  | 细辛 | 小毒 | **1~3g,散剂每次0.5~1g**(细辛不过钱指散剂);反藜芦;阴虚阳亢头痛、肺燥干咳忌 |
  | 苍耳子 | 有毒 | **3~9g,炒去硬刺**;一次超30g或炮制不当致肝肾损害、痉挛死亡;血虚头痛不宜 |
  | 马钱子 | 大毒 | 0.3~0.6g 炮制入丸散(本库眼科一般不入方,存目) |
  | 朱砂(磁朱丸) | 含硫化汞 | 不宜多服久服;朱砂含汞,磁朱丸等含朱砂方须医师把控、不宜长期 |
  | 雄黄/铅丹/硼砂 | 矿物毒 | 雄黄忌火煅;铅丹(黄丹)含铅;硼砂外用为主、内服宜慎 |
  | 千里光 | 肝毒生物碱 | 含吡咯里西啶生物碱,勿过量久服;脾胃虚寒慎 |

## 三、马兜铃酸与重金属眼用警示
- **马兜铃酸六药**(关木通/广防己/寻骨风/青木香/天仙藤/马兜铃):一律提示肾毒并建议替代——眼用/内服皆须规避(与 `通用中医/安全-配伍妊娠禁忌与毒性药.md` 一致)。
- **重金属眼用制剂**(含铅丹、雄黄、朱砂):只可建议正规制剂并严格限疗程,**不指导自制、不长期**。

## 四、忌口(眼科相关)
- **实火外障(红痛焮肿)**:忌辛辣、羊肉、酒、海鲜发物(助火生风)。
- **脾胃湿热(睑弦赤烂、针眼、痰核)**:忌肥甘厚味、甜腻(助湿生痰)。
- **阴虚内障(干涩昏花)**:忌辛辣燥热伤阴。
- **绿风内障(青光眼)**:除用药禁忌外,忌一次性大量饮水(短时间内大量饮水可升高眼压)、忌暗环境久留、忌情绪激动(诱发)。
- **通用**:服药期间忌生冷粘滑(见 `通用中医/安全-配伍妊娠禁忌与毒性药.md` 第六节)。

## 五、使用纪律
1. 凡答案出现具体药名/方名/点眼药,**必过本表+`通用中医/安全-配伍妊娠禁忌与毒性药.md` 四关**(性能→配伍→人群→剂量炮制,见 SKILL 涉药四关)。
2. 青光眼患者处方现扩瞳倾向药,**必须明示"与开方医师确认"**,不表述为"可用"。
3. 点眼药、有创外治一律 B 级/禁自行,不滑向"你照做"。
4. 剂量为教材参考值,须执业中医师/中医眼科医师面诊确定;古方原量仅文献记载。
